# Эмулятор командной строки UNIX-подобной ОС (Вариант 2)

## 1. Общее описание
Данное приложение представляет собой GUI-эмулятор языка оболочки ОС, имитирующий работу терминала UNIX-подобных систем. 
Заголовок графического окна формируется динамически на основе реальных данных системы: `Эмулятор - [username@hostname]`.

## 2. Описание всех функций и настроек
- Графический интерфейс оболочки (GUI).
- Динамический заголовок окна с данными пользователя и хоста.
- Парсер команд с поддержкой раскрытия системных переменных окружения (например, `$HOME`).
- Команды первого этапа: `ls`, `cd` (заглушки) и `exit`.

## 3. Описание команд для сборки проекта и запуска тестов
### Запуск приложения на Windows:
```cmd
run.bat
```
### Запуск модульных тестов:
```bash
pytest
```
